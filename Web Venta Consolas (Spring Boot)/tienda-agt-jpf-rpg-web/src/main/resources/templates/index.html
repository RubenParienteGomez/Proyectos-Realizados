Preguntas Frecuentes

¿Qué hacer si mi consola se sobrecalienta?

Asegúrate de que tenga suficiente espacio alrededor para ventilar. La acumulación de polvo puede causar que se apague.

¿Con qué frecuencia limpiar?

Se recomienda al menos una vez al mes para evitar acumulación de polvo y sobrecalentamiento.

¿Qué es el "drift"?

Si la cámara o personaje se mueve solo, indica un fallo en los joysticks del mando, por lo que deberás cambiarlos.

¿Modo reposo o apagar?

Apagar completamente es mejor si no se va a usar durante un tiempo prolongado para ahorrar energía y evitar sobrecalentamiento.
