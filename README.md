# Proyectos Realizados

Este repositorio centraliza diversos proyectos desarrollados a lo largo del curso, cubriendo desde aplicaciones de red en Java hasta desarrollo web moderno con Spring Boot y tecnologías frontend.

---

## Contenido del Repositorio

### 1. Chat Cliente-Servidor (Java)
Una aplicación de mensajería instantánea basada en sockets que permite la comunicación en tiempo real entre múltiples clientes y un servidor central.
* **Tecnologías:** Java SE, Sockets (TCP/IP), Multihilo.
* **Ruta:** `./Chat Cliente-Servidor (Java)`

### 2. Web Venta Consolas (Spring Boot)
Proyecto colaborativo de una tienda e-commerce dedicada a la venta de videojuegos y consolas. Incluye gestión de inventario y carrito de compras.
* **Equipo:** Desarrollado junto a dos compañeros de clase.
* **Tecnologías:** Java, Spring Boot, Spring Data JPA, Thymeleaf / REST API.
* **Ruta:** `./Web Venta Consolas (Spring Boot)`

### 3. Web Piscinas (HTML + CSS)
Práctica de diseño web estático para una empresa de servicios de mantenimiento y construcción de piscinas. Se enfoca en el diseño visual y la estructura semántica.
* **Tecnologías:** HTML5, CSS3 (Responsive Design).
* **Ruta:** `./Web Piscinas (HTML + CSS)`

---

## Cómo ejecutar los proyectos

Cada carpeta contiene su propio archivo de instrucciones específico, pero de forma general:

1.  **Chat Java:** Ejecutar primero la clase `Servidor` y luego las instancias de `Cliente`.
2.  **Spring Boot:** Requiere tener instalado el JDK 17+ y Maven. Ejecutar mediante la clase `TiendaAgtJpfRpgWebApplication`.
3.  **Web Piscinas:** Basta con abrir el archivo `index.html` en cualquier navegador.
